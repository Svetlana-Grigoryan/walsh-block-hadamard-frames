# Changelog

## v1.0.0 — 2026-09-09

Initial public reproducibility release supporting the article:

**Exact Erasure Thresholds and Sharp Stability Profiles for Structured Walsh--Block-Hadamard Frames**

Included:
- exhaustive threshold verification for selected small cases;
- exhaustive checks of the sharp partial-Walsh norm formula in the proved small-dimensional range;
- exact critical-pattern counting checks;
- fixed-seed random-erasure profiles for N=64;
- fixed-pattern stability/Frobenius-bound assessment;
- decoder verification;
- weighted two-branch stability verification;
- reproducibility figures and raw machine-readable result files;
- verified environment information;
- GitHub/Zenodo citation metadata and integrity hashes.

The unpublished manuscript source and manuscript PDF are not part of the public release.
