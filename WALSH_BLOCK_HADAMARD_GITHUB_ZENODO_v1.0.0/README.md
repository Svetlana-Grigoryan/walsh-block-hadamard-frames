# Exact Erasure Thresholds and Sharp Stability Profiles for Structured Walsh--Block-Hadamard Frames

Public reproducibility archive for the associated article by **Sergo A. Episkoposian** and **Svetlana A. Grigoryan**.

This repository contains the numerical verification code, fixed-seed experiments, machine-readable results, reproducibility figures, environment specifications, and release metadata required to reproduce the computational checks supporting the article. **The unpublished manuscript source and manuscript PDF are intentionally not included in this public software/data release.**

## Scientific scope

The archive supports exact-analysis results for the redundancy-two Parseval family

\[
F_{N,r}=2^{-1/2}\begin{pmatrix}H_N\\ I_{N/2^r}\otimes H_{2^r}\end{pmatrix}.
\]

The computational material verifies implementation-level consequences of the analytical results, including exact erasure thresholds, small-dimensional exhaustive stability checks, critical-pattern counts, the sharp worst-case profile in the proved range, the weighted-branch identity, decoder reconstruction, and fixed-seed random-erasure profiles.

**Numerical experiments are verification and illustration only; the exact theorems are established analytically in the associated article.**

- `CITATION.cff` — GitHub citation metadata.
- `.zenodo.json` — Zenodo release metadata.
- `RELEASE_MANIFEST.csv` — file sizes and SHA-256 hashes for release contents.
- `SHA256SUMS.txt` — integrity hashes for all release files except the checksum file itself.

## Quick reproduction

A Python 3.11 Conda environment is provided in `environment.yml`. The archived verification was also successfully run with **Python 3.13.5**; see `docs/ENVIRONMENT_VERIFIED.txt`.

```bash
python -m venv .venv
# Linux/macOS
source .venv/bin/activate
# Windows PowerShell
# .venv\\Scripts\\Activate.ps1

python -m pip install --upgrade pip
pip install -r requirements.txt
python code/run_all.py
```

For Conda users:

```bash
conda env create -f environment.yml
conda activate walsh-erasure
python code/run_all.py
```

To regenerate the reproducibility figures that are generated by code:

```bash
python code/make_new_figures.py
```

See `docs/REPRODUCIBILITY.md` for expected outputs and verification details.
