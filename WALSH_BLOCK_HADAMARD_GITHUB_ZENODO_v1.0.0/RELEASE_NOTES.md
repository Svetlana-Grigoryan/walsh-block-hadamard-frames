# Release notes — v1.0.0

Initial public software/data release supporting the article **Exact Erasure Thresholds and Sharp Stability Profiles for Structured Walsh--Block-Hadamard Frames**.

## Recommended GitHub release title

`v1.0.0 — Reproducibility package for Walsh–block-Hadamard erasure stability`

## Release contents

This release contains the exact verification code, fixed-seed experiments, machine-readable numerical outputs, reproducibility figures, environment specifications, and integrity metadata used to support the computational checks reported in the associated article.

The unpublished manuscript source and manuscript PDF are intentionally **not** included in this public release.

All random experiments use fixed seeds. Exact theorems are analytical results; the computations in this repository verify implementations, reproduce numerical outputs, and illustrate the theory.

After GitHub creates the release and Zenodo archives the tag, do not modify that tag. Use a new version for later corrections, and cite the Zenodo **version DOI** for the exact archived software state.
